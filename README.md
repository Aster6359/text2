## 1. 构造三组像素

把灰度值简化为四级：0、1、2、3。自己把下列三组数据写成 Python 列表，先猜哪组熵最大。

| 模拟画面 | 像素值 | 预期信息熵 |

## 3. 检查结果，写下观察

- **最小值：** 纯色图里每次都能猜中灰度值，所以熵为 0。
- **最大值：** 对四个可能的灰度等级，均匀分布的熵最大，为 `log2(4) = 2` bits。
- **打乱像素：** 将第三组改成 `0, 3, 1, 2, 3, 0, 2, 1` 再运行。为什么结果仍是 2 bits？

灰度直方图的熵只看各灰度值出现的频率，不看像素的位置。它可以衡量随机抽取一个像素时，其灰度值的不确定性，但不能凭单帧熵判断视频有没有运动。要研究帧间冗余，可以在挑战 3 比较两帧的联合分布。
